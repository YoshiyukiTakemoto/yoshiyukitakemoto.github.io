Daily sudoku

A new puzzle every day at three difficulty levels, the same for everyone. Keep your streak going, or play unlimited practice puzzles. Progress saves automatically.

0:00 0 0

How to use

  1. Pick Easy, Medium or Hard. Everyone playing today gets the same puzzle.
  2. Tap a cell, then tap a number. On a keyboard, use the arrow keys and 1–9.
  3. Turn on Notes (or press N) to pencil in candidates.
  4. Solve the daily puzzle each day to build a streak, then share your time.

How to play sudoku

Fill the 9×9 grid so that every row, every column and every 3×3 box contains the digits 1 to 9 exactly once. Every puzzle here has exactly one solution and can be solved by logic, without guessing.

Solving tips

  • Single position: if a digit fits in only one cell of a row, column or box, it goes there.
  • Single candidate: if a cell can only take one digit, write it in.
  • Use notes on harder puzzles to track candidates, and clear them as you place digits.

Frequently asked questions

When does the daily puzzle change?

At midnight in your own time zone.

Is my game saved if I close the tab?

Yes. Each puzzle’s progress, time and notes are saved in this browser.

What counts as a mistake?

Placing a digit that doesn’t match the solution. You can hide mistake highlighting for a harder challenge; mistakes are still counted.
