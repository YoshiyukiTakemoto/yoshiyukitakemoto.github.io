JSON formatter and validator

Paste JSON to pretty-print it, minify it or check it for errors. The error message points to the line and column. Your data never leaves your browser.

How to use

  1. Paste JSON into the left box. It is checked as you type.
  2. Press Format to indent it, or Minify to put it on one line.
  3. Turn on Sort keys to order object keys alphabetically, which makes two files easier to compare.
  4. Copy the result or download it as a .json file.

Common JSON errors

  • Trailing comma: [1, 2,] is not allowed in JSON.
  • Single quotes: strings and keys must use double quotes.
  • Unquoted keys: {name: 1} must be {"name": 1}.
  • Comments: JSON has no comments. Remove // and /* */.
  • Special values: NaN, Infinity and undefined are not valid.

Frequently asked questions

Is it safe to paste API responses or config files?

Yes. Formatting uses your browser’s built-in JSON parser. Nothing is uploaded, logged or stored.

How large a file can it handle?

Several megabytes is fine on most computers. Very large files depend on your device’s memory.

Does sorting keys change the data?

No. JSON objects are unordered, so sorting keys keeps the same meaning. Array order is never changed.
