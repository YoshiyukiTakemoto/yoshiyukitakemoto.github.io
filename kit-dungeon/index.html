Kit Dungeon: daily roguelike RPG

A turn-based dungeon crawler. Every floor is generated as you go down. Fight monsters, level up, find better gear and descend as deep as you can. One life per run.

    How to use

    1. Choose Today’s dungeon (the same layout for everyone today) or a new random dungeon.
    2. Move with the arrow keys or WASD. On phones, use the pad or tap the map. Walk into a monster to attack it.
    3. Step on items to pick them up. Better weapons and armour are equipped automatically. Press 1–8 to use potions, bombs and scrolls.
    4. Find the golden stairs and press Enter to go deeper. Your run saves every turn, so you can close the page and come back.

    How it works

    Each action takes one turn, and monsters move after you. You see only what is in your line of sight; explored areas stay on the map. Monsters get stronger the deeper you go, so balance fighting for experience against hurrying down. When your HP reaches zero the run ends and you start again from floor B1.

    Items

    • Potion: restores some HP.
    • Elixir: restores all HP.
    • Bomb: damages every monster in sight.
    • Teleport scroll: moves you to a random spot on the floor. Useful when surrounded.

    Frequently asked questions

    What is a roguelike?

    A game genre with randomly generated levels, turn-based movement and permanent death. Every run is different, so you learn and improve rather than memorise.

    Is today’s dungeon really the same for everyone?

    Yes. The floors are generated from today’s date, so everyone gets the same layouts, monsters and items. Combat rolls still vary.

    Is my progress saved?

    Yes. The current run saves in this browser after every turn.
