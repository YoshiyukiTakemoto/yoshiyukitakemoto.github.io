QR code generator that never expires

Create QR codes for links, Wi‑Fi, contacts and more. The data is stored in the code itself, so it keeps working forever with no redirect service in between.


  







How to use


  1. Choose what the code should do: open a link, join Wi‑Fi, save a contact, write an email, call or text.
  2. Fill in the fields. The code updates as you type.
  3. Adjust error correction, size, quiet zone and colours if needed. A warning appears if the colours are hard to scan.
  4. Download a PNG for screens and documents, or an SVG for print.


Static vs dynamic QR codes


Many QR code sites create dynamic codes: the code points to their short link, which then redirects to your page. If the service shuts down or asks for payment, every printed code stops working. This generator makes static codes. Your link or text is encoded directly, so the code works as long as the destination does.


Choosing error correction


  • L (7%): smallest code, best for screens.
  • M (15%): a good default for most uses.
  • Q (25%): for printed codes that may get scratched or dirty.
  • H (30%): for codes with a logo placed on top, or rough surfaces.


Frequently asked questions


Do these QR codes expire?
No. They are static codes with your data inside. There is no server that can turn them off.
Is my Wi‑Fi password safe?
The code is made entirely in your browser. Nothing you type is sent anywhere. Anyone who scans the printed code can read the password, so only share it where you would share the password.
What size should a printed QR code be?
At least 2 × 2 cm (about 0.8 inch) for scanning at arm’s length. As a rule, the scanning distance should be no more than about 10 times the code width. Keep the white quiet zone around it.
Can I use the codes commercially?
Yes. The codes you create are yours to use anywhere, including on products and printed materials.
