WordPress security check

Enter a site address to check its WordPress version, plugins and common weak spots in about 10 seconds. Only public pages are read, the same ones any visitor’s browser loads. Unlike our other tools, this one runs on our server, because browsers can’t read other sites directly. The address you enter isn’t stored.

    How to use

    1. Enter the site address, such as example.com.
    2. Confirm that you own or manage the site, or have permission to check it.
    3. Press Check site. Results are grouped into Fix now, Improve and OK, each with how to fix it.
    4. Check the plugin table for components with updates or that were removed from wordpress.org.

    What this tool checks

    • WordPress version, compared with wordpress.org’s list of secure and insecure releases.
    • Plugins and themes loaded on the home page: available updates, removal from the official directory, and plugins with no update for two years.
    • Exposed files: debug.log, readme.html and browsable upload folders.
    • Attack surface: XML-RPC and the REST API user list.
    • HTTPS and headers: HTTPS redirect, HSTS, X-Content-Type-Options and clickjacking protection.
    • PHP version, when the server announces it.

    Why outdated plugins matter

    Most hacked WordPress sites aren’t broken into through WordPress itself but through a plugin or theme with a known vulnerability. Once a fix is published, attackers scan the web for sites still running the old version, often within days. Keeping plugins updated, and replacing ones that are no longer maintained, is the single most effective protection.

    What this check can’t see

    The scan reads public pages from outside, like a visitor. It can’t see the admin area, server files, the database or plugins that only load on other pages. A clean result lowers risk but doesn’t prove a site is safe. For a full picture, also review the plugin list in the dashboard and keep regular backups.

    Frequently asked questions

    Is it safe to run this on my site?

    Yes. It sends about 10–40 ordinary page requests, the same kind a browser makes. It never logs in, submits forms or tries passwords.

    Can I check someone else’s site?

    Only check sites you own or manage, or that you have permission to check. Requests are rate-limited.

    Do you store the address or results?

    No. Results are cached for 10 minutes so repeated checks don’t hit the site again, then discarded. If you join the monitoring waitlist, we keep your email and the site address you checked.

    Why does a plugin show “Not in the wordpress.org directory”?

    Paid and custom plugins aren’t listed on wordpress.org, so their latest version can’t be checked here. Check for updates with the plugin’s vendor.

    Why is the WordPress version unknown?

    Many sites hide it, which is good practice. The version can then only be checked from the dashboard.
