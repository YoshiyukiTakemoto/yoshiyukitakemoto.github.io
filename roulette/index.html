Spin the wheel

Type a list of names or options and spin the wheel to pick one at random. Great for classrooms, giveaways, team meetings and deciding what to eat.

    How to use

    1. Type one item per line on the right. The wheel updates as you type.
    2. Press Spin (or the space bar).
    3. Turn on Remove the winner to pick each item only once, for example to set a speaking order.
    4. Your list is saved in this browser, so it’s there next time.

    Is it fair?

    Every item gets an equal slice of the wheel, and the stopping point comes from your browser’s cryptographic random number generator. Each spin is independent of the last.

    Frequently asked questions

    How many items can I add?

    As many as you like. Above about 40 the labels get very small, but the draw stays fair.

    Can I use it on a projector or live stream?

    Yes. It works full screen in any browser and the wheel is large and readable.

    Can I make one item more likely?

    Type it on more than one line. Each line gets its own slice.
