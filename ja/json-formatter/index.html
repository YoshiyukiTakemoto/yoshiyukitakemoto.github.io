JSON整形・検証

JSONを貼り付けるだけで、見やすく整形したり、1行に圧縮したり、構文エラーをチェックしたりできます。エラーは行と位置で表示します。データはブラウザの外に出ません。

使い方

  1. 左側にJSONを貼り付けます。入力に合わせて自動でチェックします。
  2. 整形でインデント付きに、圧縮で1行にします。
  3. キーを並べ替えをオンにすると、キーがアルファベット順になり、2つのJSONを比較しやすくなります。
  4. 結果をコピーするか、.jsonファイルとして保存します。

よくあるJSONのエラー

  • 末尾のカンマ：[1, 2,] のような最後のカンマは使えません。
  • シングルクォート：文字列とキーはダブルクォート（"）で囲みます。
  • キーのクォート忘れ：{name: 1} は {"name": 1} と書きます。
  • コメント：JSONにコメントは書けません。// や /* */ を削除してください。
  • 全角の記号や空白：全角のコロン・カンマ・スペースが混ざるとエラーになります。

よくある質問

APIのレスポンスや設定ファイルを貼り付けても安全ですか？

はい。ブラウザ標準のJSONパーサーで処理し、データの送信・記録・保存は一切しません。

どれくらいの大きさまで扱えますか？

数MB程度なら多くのパソコンで問題なく動作します。非常に大きなファイルは端末のメモリ量に左右されます。

キーを並べ替えるとデータが変わりますか？

変わりません。JSONのオブジェクトは順序を持たないため、意味は同じです。配列の順序は変更しません。
