文字数カウント

文章を入力または貼り付けるだけで、文字数・行数・段落数・バイト数をすぐに数えます。原稿用紙の枚数やX（Twitter）の文字数換算も表示します。

0

使い方

  1. 文章を入力欄に入力するか、貼り付けます。
  2. 右側に結果が表示されます。入力のたびに更新されます。
  3. 目標文字数を入れると、あと何文字か、何文字オーバーかがわかります。レポートやES（エントリーシート）の字数制限に便利です。
  4. 入力した文章はこのブラウザ内に保存されるため、タブを閉じても続きから再開できます。

主な文字数の目安

用途文字数
X（Twitter）の投稿全角140文字（半角280文字）
Googleの検索タイトル全角30文字前後
メタディスクリプション全角80〜120文字前後
原稿用紙1枚400文字（20字×20行）
Instagramのキャプション2,200文字

文字の数え方

見た目で1文字に見える単位（書記素クラスタ）で数えるため、絵文字👨‍👩‍👧や濁点付きの合成文字も1文字として数えます。原稿用紙の枚数は空白・改行を除いた文字数を400で割った目安で、句読点のぶら下げや改行による空きマスは考慮していません。

よくある質問

入力した文章は送信されますか？

いいえ。文字数の計算はブラウザ内で行い、文章はどこにもアップロードされません。

空白や改行は文字数に含まれますか？

一番大きく表示される文字数には空白と改行を含みます。右側に「空白を除く」「空白・改行を除く」文字数も表示します。

Xの文字数が通常の文字数と違うのはなぜ？

Xでは日本語などの全角文字と絵文字を2、URLは長さに関係なく23として数えるためです。上限は280（全角140文字）です。

Shift_JISのバイト数は正確ですか？

半角英数字と半角カナを1バイト、それ以外を2バイトとして計算した目安です。Shift_JISにない文字も2バイトとして数えます。
