数独（ナンプレ）毎日の問題

毎日新しい問題を3つの難易度で出題します。問題は全員共通なので、タイムを友達と比べられます。練習問題は何問でも遊べ、途中経過は自動で保存されます。

0:00 0 0

使い方

  1. 初級・中級・上級を選びます。今日遊ぶ人は全員同じ問題です。
  2. マスをタップしてから数字をタップします。キーボードでは矢印キーと1〜9で入力できます。
  3. メモをオン（またはNキー）にすると、候補の数字を小さく書き込めます。
  4. 毎日解いて連続日数を伸ばし、タイムをシェアしましょう。

数独のルール

9×9のマスに、どの行・どの列・どの3×3のブロックにも1〜9の数字が1つずつ入るように埋めます。このサイトの問題はすべて答えが1つだけで、当てずっぽうに頼らず理詰めで解けます。数独はナンプレ（ナンバープレース）とも呼ばれます。

解き方のコツ

  • 入る場所が1つだけ：ある数字が、行・列・ブロックの中で1か所にしか入らないなら、そこに決まります。
  • 入る数字が1つだけ：あるマスに入れられる数字が1つしかなければ、それに決まります。
  • メモを使う：上級では候補をメモし、数字が決まるたびに消していくと解きやすくなります。

よくある質問

今日の問題はいつ切り替わりますか？

お使いの端末の時刻で、毎日0時に切り替わります。

途中でタブを閉じても続きから遊べますか？

はい。問題ごとに、入力内容・タイム・メモがこのブラウザに保存されます。

ミスはどう数えられますか？

答えと違う数字を入れるとミスになります。「間違いを赤で表示」をオフにすると表示されなくなりますが、回数は数えられます。
